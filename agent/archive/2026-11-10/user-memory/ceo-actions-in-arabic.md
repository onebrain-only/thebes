CEO 2026-10-18: "بعتلي الاكشنز اللي انت محتاجها مني دايما بالعربي". Whatever I ask him to do (portal steps, Terminal commands, approvals), I write the request and the steps in Arabic, even if the surrounding report or a short status line drifted into English. Commands, file paths, button labels and portal names stay as they appear on screen, but the explanation and order of steps are Arabic.

**Why:** he lost track when action requests came in English during long sessions.
**How to apply:** before sending any message that contains an action for him, check the action block is Arabic; keep one numbered list, exact place, what to click/type, what to accept or reject. Related: [[ceo-delegates-decisions]].
