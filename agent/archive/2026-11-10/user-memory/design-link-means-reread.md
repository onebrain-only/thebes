When the CEO gives a task with a design link, the team must open and read the design fresh at that moment and implement it as is. Never rely on an earlier read, a prior frame, or what a previous ticket built.

**Why:** KAN-640 R2 was built from an old version of Location.dc.html. The CEO called it "the biggest mistake": a new task with a design link means go and see the design again.

**How to apply:** Every UI brief must say: read the linked design now. Record the file's current etag or version and the read time in the report. Implement it exactly. If the design can't be read, stop and report BLOCKED; never build from memory or old code. Related: [[designs-from-claude-design]], [[ceo-tests-localhost-first]].
